## 👋 About

I'm a software engineer with over a decade of experience building production systems, primarily in fintech where reliability and precision aren't negotiable. My work focuses on architecting distributed systems that scale, writing maintainable code, and contributing to open source projects that matter.

I believe great software engineering is about more than writing code—it's about understanding problems deeply, designing solutions thoughtfully, and building systems that stand the test of time. Over the years, I've learned that the best code is code that your future self and teammates will appreciate: well-structured, properly tested, and maintainable.

I also mentor developers and contribute to open source when I can. The community has given me so much, and I try to pay it forward.
